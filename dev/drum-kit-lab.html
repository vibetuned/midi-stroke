Drum kit lab

The synthesized kit from src/utils/drumKit.ts, which the Drums app plays when you hit a pad. Click a voice to hear it. The table below renders each voice offline and measures it, so the kit can be checked without ears: level, how long it rings, and where its energy sits in the spectrum. Run it with npm run dev and open /dev/drum-kit-lab.html.
