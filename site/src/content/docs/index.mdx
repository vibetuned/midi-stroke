Midi Stroke connects your MIDI instrument to professionally engraved sheet
music (Verovio + MEI) and scores what you play, note by note. Two modes on
every piece: **Rhythm** — play along in time, scored with hit/miss windows —
and **Practice** — playback pauses on each note and waits until you press the
right one.

## Install it

The desktop app is the way to run it: MIDI goes through **CoreMIDI, WinMM or
ALSA** directly, so any browser situation stops mattering, hot-plugging a
controller just works, and the whole trainer runs offline.

<Tabs syncKey="os">
  <TabItem label="macOS" icon="apple">
    ```sh
    brew install --cask vibetuned/tap/midi-stroke
    ```
    One universal build for Apple Silicon and Intel, signed and notarized.
  </TabItem>
  <TabItem label="Windows" icon="seti:windows">
    ```sh
    winget install Vibetuned.MidiStroke
    ```
    Or run the installer from the [releases page](https://github.com/vibetuned/midi-stroke/releases).
  </TabItem>
  <TabItem label="Linux" icon="linux">
    ```sh
    sudo curl -fsSL https://ms.vibetuned.com/apt/midi-stroke.asc -o /etc/apt/keyrings/midi-stroke.asc
    echo "deb [signed-by=/etc/apt/keyrings/midi-stroke.asc] https://ms.vibetuned.com/apt stable main" | sudo tee /etc/apt/sources.list.d/midi-stroke.list
    sudo apt update && sudo apt install midi-stroke
    ```
    An AppImage is on the [releases page](https://github.com/vibetuned/midi-stroke/releases) for everything else.
  </TabItem>
</Tabs>

All the details, including what each platform ships and how updates arrive,
are on the [desktop app page](desktop/). No installation handy? The
[web app](https://ms.vibetuned.com/app/) runs the same trainer in any browser
with Web MIDI (Chrome, Edge, Opera).

## Bring your own scores

Load a single MEI file, or import a whole **ZIP of MEI scores** as a new
collection stored permanently on your device — no server needed. Scores
don't need any special preparation: the app adds its one-beat count-in
measure automatically. [Songs & importing →](songs/)
